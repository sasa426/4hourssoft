공중콩 고객 지원

공중콩은 공인중개사 기출문제와 연습문제, OX 문제를 풀고 복습할 수 있는 학습 앱입니다. 앱 이용 중 궁금한 점이나 불편한 점이 있으면 아래 이메일로 알려 주세요.

자주 묻는 질문

학습 기록은 어디에 저장되나요?

학습 기록은 사용 중인 기기에 저장됩니다. 계정이나 기기 간 자동 동기화 기능은 없습니다.

기기를 바꾸거나 앱을 삭제하기 전에 학습 기록은 어떻게 보관하나요?

앱 설정에서 학습 기록을 JSON 파일로 내보내 보관해 주세요. 새 기기에서는 해당 파일을 직접 가져올 수 있습니다. 앱을 삭제하기 전에 기록을 별도로 보관해 주세요.

문제나 해설의 오류는 어떻게 알리나요?

화면에 표시된 시험연도와 회차, A형·B형, 1차·2차 구분, 과목, 문제 번호와 오류로 보이는 부분을 이메일로 알려 주세요. 가능하면 어떤 내용으로 고쳐야 하는지도 적어 주세요. 개인 학습 기록 JSON 파일 원본은 보내지 않으셔도 됩니다. 화면을 첨부한다면 개인 정보가 보이지 않도록 가려 주세요.

앱 이용·오류·기능 문의

앱 오류, 이용 방법, 기능에 관한 의견은 4hours.soft@gmail.com으로 보내 주세요. 문제를 살펴볼 수 있도록 사용 기기와 운영체제를 알려 주세요. 문제가 생긴 화면과 그때 하신 일을 순서대로 알려 주세요.

비밀번호나 주민등록번호 등 민감한 정보와 학습 기록 JSON 파일 원본은 보내지 말아 주세요.
